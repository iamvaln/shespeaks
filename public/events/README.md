# Event posters (call for speakers)

Put one image per event here (JPG or WebP, about 1000 px wide, under 250 KB), for example:

- `devfest-douala-2026.jpg`
- `devfest-yaounde-2026.jpg`

Then open **Admin → Événements**, edit the event, and set *Affiche* to `/events/devfest-douala-2026.jpg`.
The poster then replaces the branded card on the home page. Without a poster, the card still shows the event name, deadline and dates.
